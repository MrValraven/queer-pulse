# QueerPulse robots policy
#
# Posture: DELIBERATELY QUIET. Only the public-service surface is indexed:
# resources, safety, about/governance, policies and the local arrival guides.
# The magazine, cinema, studio, activism, archive and sustainer surfaces are
# intentionally NOT indexed; they rely on word-of-mouth and direct sharing.
# The gated member surface is disallowed outright.
#
# Sources of truth:
#   - public-vs-gated: GATED_PATTERNS in src/app/authGate.ts
#   - the indexed list: QUIET_PUBLIC_PATHS in scripts/publicPaths.mjs
#
# This file is static and cannot import either, so `scripts/check-robots.mjs`
# holds it to them: it runs in the build gates (`pnpm check:robots` to run it
# alone) and fails the build when a gated prefix is missing from the Disallow
# list, when a path the sitemap advertises is blocked, or when a Disallow blocks
# a page authGate calls public. A deliberate block of a public page (the
# de-indexed surfaces below) is declared in ACCEPTED_EXTRA_DISALLOWS there.
#
# See docs/superpowers/specs/2026-07-20-seo-and-ai-discoverability-design.md

# ---------------------------------------------------------------------------
# AI crawlers: allow RETRIEVAL, block TRAINING.
#
# Retrieval crawlers fetch a page at answer time and cite it with a link back,
# so a person asking an AI for queer healthcare guidance in Lisbon can still be
# pointed here, and the words stay on our domain. Training crawlers absorb
# community writing into model weights without attribution; our members did not
# consent to being training data.
#
# This is a statement of intent with partial enforcement: robots.txt is
# voluntary, and Bytespider and some stealth crawlers are documented ignoring
# it. It does not hide anything from a determined scraper.
# ---------------------------------------------------------------------------
